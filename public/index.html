Key Features

🔒

Idempotency

Unique client_ref primary key with request fingerprinting. Duplicate sends return the stored result; conflicting payloads return 409.

🔄

AUTO Failover

AUTO01 tries Nexus first. Only a 5xx or timeout triggers exactly one Orbit attempt. Rate-limit exhaustion is terminal — no failover.

✍️

HMAC Webhooks

Nexus delivery webhooks are validated with timing-safe HMAC-SHA256. Event IDs provide deduplication — duplicates are acknowledged without state mutation.

📊

Full Audit Trail

Every lifecycle event, provider attempt, failover decision, and status transition is persisted in SQLite with timestamps.

🛡️

Race Safety

In-process single-flight dispatch ensures concurrent identical requests result in exactly one provider call. SQLite transactions guard persistence.

📦

Zero Dependencies

Uses only Node.js 22 built-in modules: node:http, node:sqlite, node:crypto. No node_modules at runtime.
